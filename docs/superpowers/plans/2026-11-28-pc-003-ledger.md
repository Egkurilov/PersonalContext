# PC-003 Event Ledger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Introduce the database foundation and an internal guarded visit writer while keeping activity collection disabled.

**Architecture:** Add a versioned SQLite ledger and preserve existing restore safety. A later HTTP ingress must use the single writer and require trusted source classification, consent, device binding and the capture latch; do not expose an accepting route before these are wired and verified. The first packet only establishes storage and synthetic transaction tests.

**Tech Stack:** Python 3.12, SQLite WAL, Alembic, SQLAlchemy, unittest.
