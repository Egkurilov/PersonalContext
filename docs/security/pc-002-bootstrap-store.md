# PC-002: внутренний bootstrap verifier

Миграция `0004` добавляет одну временную запись bootstrap: только SHA-256 от
случайного 256-битного кода, время выдачи/окончания и счётчик ошибок. Код
действует пять минут; новая локальная выдача заменяет предыдущий. Пять неверных
попыток, истечение срока, обратный скачок часов или повреждённая запись
аннулируют verifier. Готовый владелец исключает повторную выдачу.

Успешная проверка создаёт запись хеша владельца и удаляет verifier в одной
транзакции `BEGIN IMMEDIATE` через single-writer. Вызывать функции следует через
`Writer.submit`: возвращённый код считается выданным только после commit.
Аргон2 вычисляется заранее вне writer и SQLite-транзакции; строка пароля в
хранилище не передаётся. Откат транзакции возвращает обе операции к прежнему
состоянию. Ошибки не содержат код или пароль.

Это внутренний примитив, не API: локальное подтверждение владельца, безопасное
отображение кода, ограничение повторной выдачи и частоты обращений, сессии и
CSRF ещё не реализованы. Не открывать выдачу через сеть и не записывать код в
логи, URL или DOM. При миграции существующей БД применяется DPAPI backup;
восстановление копии в новый файл описано в README. Интерактивный сценарий и
frozen-сборка с подключённой авторизацией ещё не проверены.
