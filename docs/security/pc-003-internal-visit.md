# PC-003: внутренний writer web-визитов

`submit_web_visit` обрабатывает только `web_visit` с metadata scope и точечным
временем. До записи он проверяет device/source binding, политику и локальную
паузу, затем применяет фильтры владельца и sanitizer. Hash считается только от
очищенных данных. Событие и задание сохраняются одной SQLite-транзакцией;
после rollback подтверждение не выдаётся. Повтор идентичного очищенного события
возвращает duplicate, пересечение идентификатора или source key с другим телом —
conflict. Metadata получает 90-дневный срок хранения по умолчанию.

`SanitizerContext` и Origin здесь являются внутренними доверенными аргументами,
а не полями события. Проверка типа не доказывает происхождение или разрешения
операционной системы. Доверенный адаптер и безопасный серверный транспорт для
этого пути ещё не реализованы: **не подключать этот writer к HTTP или реальному
collector**, не включать сбор. Текущие вызовы существуют только в синтетических
тестах. Внутренний batch ограничивает вход 100 элементами и 1 МиБ UTF-8 JSON,
запрещает повторяющиеся ключи и возвращает отдельный результат после фиксации
каждого события. При сбое после частичной записи ответ не выдаётся; повторный
пакет распознаёт уже сохранённые события. Это не сетевой endpoint: будущий
транспорт обязан ограничивать тело при чтении, до выделения памяти, и передавать
только доверенную классификацию. Также отсутствуют batch API, полная схема остальных видов событий,
удаление и retention worker, нормализатор и финальная приёмка PC-003.

Для проверки IANA-часовых зон добавлен закреплённый `tzdata`; синтетический
тест проверяет DST на Windows. Frozen smoke запускает проверку IANA и импорта
writer внутри собранного процесса с временным профилем. Этот тест не проверяет
приём событий в установленном приложении.
