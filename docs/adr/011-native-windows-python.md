# ADR-011 — Нативный Windows-first модульный монолит на Python

**Принято владельцем 24.11.2026.** Эта ADR заменяет прежние решения о Docker/WSL2, PostgreSQL/pgvector, Rust agent и отдельных API/worker deployments. Продуктовые FR, безопасность, граф, интеграции и критерии качества сохраняются; Apple-specific collectors по-прежнему исключены (PC-006, PC-008). Одна установленная копия на Windows 11 x64 — центральный collector/host, дополнительные Chrome/Edge расширения могут подключаться по разрешённому приватному HTTPS. Нативные агенты на других ПК, многопользовательский сервер и кластер не входят в v1.

## Решение
- Python 3.12 (patch фиксировать, поддерживаемый upgrade через ADR), FastAPI/Pydantic, Uvicorn single process/workers=1, SQLAlchemy 2.x Core + Alembic SQLite batch migrations, встроенный sqlite3 driver. React/TS/Vite production build bundled as static assets; API и SPA same origin, SPA fallback only UI paths; нет Node runtime, nginx или отдельного web service. Не менять FastAPI ради небольшого числа зависимостей: существующие OpenAPI/validation/test contracts важнее.
- Win32 collector на Python/pywin32 (GetForegroundWindow/GetLastInputInfo, WTS/power notifications; без keyhooks). pystray Win32 + Pillow icon. Tray runs in interactive owner session; no system service, no admin/elevation. Main lifecycle coordinates tray + Uvicorn/asyncio loop; bounded I/O threads and dedicated writer thread, no blocking OCR/ML/SQLite on event loop. Named mutex scoped to Windows user + data directory; second start opens portal or exits, never second writer. Autostart current user opt-in (Startup/Task Scheduler at logon with no elevation); pause/exit controls, no capture before consent. No data while PC asleep/shutdown, no retroactive fabrication. Local collector calls the shared validated ingestion function directly (not HTTP to itself), one authoritative DB; local queue only in memory before commit, accepted = committed, don't claim uncommitted events after crash. Browser extension independent, offline bounded sanitized queue, per-event ack/retry and policy TTL; no plaintext content queued if safe storage unavailable. Native local source identity internal, browser pairing scoped as before.
- SQLite one DB on local NTFS under %LOCALAPPDATA%/PersonalContext/data (configurable local disk path; never network/sync folder). WAL, foreign_keys=ON for each connection, busy_timeout 5000ms, synchronous=FULL for acknowledged-event durability; short explicit transactions, bounded single-writer queue (backpressure, return retryable 503 when full), one writer thread owns its connection; readers separate short read transactions, no shared cursor/connections across threads. BEGIN IMMEDIATE for claim/commit operations; never hold DB lock during LLM request/CPU search or network I/O. Transaction event+job (outbox) before ack, unique keys and lease expiry/restart recovery. Scheduler and workers in same executable, asyncio tasks for I/O; configurable concurrency default 1 LLM job, durable jobs table, retry/DLQ; optional periodic enrichment every 15min with manual run, configurable resource limits and pause for high load; shutdown stops collecting, commits/drains bounded queues, returns active jobs to retry or lease recovery. On sleep/lock, close active interval and recover without phantom activity; scheduler catch-up dedup on resume; don't wake PC for jobs. No Celery/Redis/APScheduler requirement.
- SQLite FTS5 unicode61 tokenizer (RU/EN Unicode tokens, diacritics handling; no false promise of native Russian morphology). Check FTS5 support at startup and in frozen binary. BM25 + hybrid RRF. Normalized little-endian float32 BLOB embeddings per (chunk_id, model_version, dimension), no separate DB, no sqlite extension loading. For exact semantic retrieval filter eligible chunk IDs in SQL (owner/source/time/topic/project/expiry/tombstones and model version/dimension) before vector ranking. Read eligible vectors in bounded batches (e.g. 2048/4096), NumPy dot product on normalized vectors, stable top-k heap, deterministic ties by chunk ID, no all-corpus matrix requirement. CPU thread pool bounded, BLAS threads bounded, cancel/deadline, check finite/nonzero vectors and mismatched version; final read rechecks current privacy policy/expiry/tombstone before returning. Model unavailable -> FTS only; model upgrade background re-embed and atomic active version switch, delete obsolete versions by retention. Benchmark 100k chunks at actual dimension, report memory and p95 ≤2s retrieval excluding generation; only introduce local index (sqlite-vec or HNSW) if benchmark fails and separate ADR proves maintainability, filter-before-rank, purge correctness and packaging. No remote vector service.
- Local default binds exactly 127.0.0.1:17890, no 0.0.0.0, no public ports. Use local random bootstrap, Argon2id, short session cookie HttpOnly SameSite=Strict, CSRF + strict Host/Origin allowlist, rate limit, no wildcard CORS; local HTTP cookie Secure exception only for exact loopback (remote HTTPS always Secure); validate Host even on loopback against DNS rebinding, reject non-loopback peers on local listener, browser extension origin/pairing allowlist and bearer token; no tokens in URL or DOM. No ambient trust just because caller is localhost. Port conflict fails with visible tray diagnostics or owner-configured port, never silently open network listener. Optional LAN/VPN access OFF; enable separately in settings, bind explicitly to selected private interface and trusted TLS certificate with Uvicorn, firewall allow only private subnet/VPN; no direct internet, no insecure remote HTTP, no model port exposure. Remote browser collectors only when HTTPS reachable; show offline and bounded queue if host is off. Validate Origin/Host and TLS for remote too. UI can be opened on mobile without Apple SDK. MCP stdio command uses separate scoped token + local API; no direct DB access; may run as short-lived client process launched by Codex, does not start second collector/host.
- Files stored under current user's ACL, not executable install directory; DPAPI for credentials and encryption key material; SQLite is NOT encrypted at rest by default. BitLocker/device encryption recommended and warning when not enabled; don't equate DPAPI with DB encryption. Backups encrypted with authenticated encryption and owner-recoverable secret or explicit machine/user-bound DPAPI mode, SQLite online backup API with integrity check, include migration/version and deletion tombstones, don't copy open DB/WAL manually. For privacy purge secure_delete (incl FTS shadow-table behavior verified), delete FTS/chunks/jobs/snapshots, checkpoint/truncate WAL when safe, compact/VACUUM when appropriate with disk quota; immediate logical suppression and ≤24h active store cleanup, no guarantee forensic erasure from SSD, OS snapshots or previously exported copies. Retention/backup limits unchanged.
- Packaging: PyInstaller --onedir (embedded Python, native wheels, React dist, migrations and FTS5), build on Windows x64; Inno Setup per-user .exe installer, no administrator/runtime/Docker/WSL/Node/Python required on target. Installer upgrades stop old app, backup before migration, version check and rollback documented; uninstaller asks preserve/delete data; no silently starting capture, no forced model installation. Local model Ollama/LM Studio is optional separately installed dependency for AI, tested offline degraded mode. Signature/SmartScreen limitations disclosed, checksums and signed releases when signing available. Dev: lockfile/venv via uv, Python 3.12, Node LTS for frontend build only, npm ci, PowerShell scripts dev/build/test; Windows CI for bundle smoke plus platform-independent unit tests. Never put personal data in repo/bundle.
- Restore deliberately invalidates authentication and consent rather than resurrecting their older state: before publishing the restored file, remove owner credentials, sessions and pending bootstrap/pairing codes, revoke device credentials, and pause and expire capture policy. The owner must locally bootstrap a new password and re-pair devices. Preserve other restored data and require a new file; unsupported versioned schemas fail closed. Subsequent migrations must extend the restore rules before release.
- NFR: current original synthetic scale (900k events/100k chunks/1000 topics), reference Win11 SSD 8 logical cores/16GB or better, record actual benchmark; target idle combined app avg ≤2% CPU, working set ≤250MB without active search/model/OCR, peaks during vector scan/import reported, tray/health ready ≤5s cold start target, portal render ≤3s initial (≤1s warm target), existing ingestion/timeline/retrieval p95 and model-quality/backup gates. No claims until measured. 100% acknowledged events preserved in application restart tests; 72h offline applies to browser queue if capacity allows. If host is not running there is no collection of local OS activity; distinguish gaps.
