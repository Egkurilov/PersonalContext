# Исследование платформ и ADR (24.11.2026)

## Источники и выбор

**Решение владельца 24.11.2026:** Apple-specific сбор исключён из v1. Основной путь Windows foreground + Chromium, исторические импорты. Исследование Safari/Screen Time ниже сохраняется только как обоснование отказа, не как roadmap. Native macOS и iOS не требуют сборки, entitlement или проверок для релиза. Стандартный Chrome на Mac — browser-only, без native host.

## ADR decisions
1. Local-first single-owner, opt-in; сервер только private LAN/VPN TLS. Не облачный аналитический сервис.
2. In-process Python pywin32 collector + pystray, optional ActivityWatch import, не fork. Нативный fallback гарантирует политику до persistence.
3. SQLite authoritative WAL+FTS5+float32 BLOB and NumPy exact cosine + edge tables + durable jobs. Supersedes PostgreSQL/pgvector decision (ADR-011).
4. Signals != facts: explicit granularity, playback vs reading, temporal scores, user overrides; every derived claim evidence, reject unsupported.
5. Privacy first, not retroactive redaction: app/domain deny + separate content/OCR consent + fail-closed; no hidden recording. User's correction/purge propagates into index, graph and exports.
6. Apple-specific collection excluded; browser-only Chrome can run independently of Windows agent. No Apple entitlement, Safari or iOS work in v1; revisit only via separate owner decision.
7. Local model adapter with deterministic scoring; no cloud fallback. RU/EN and regression eval are required.
8. Web portal primary, responsive, read-only local MCP and managed Obsidian export.
9. CI synthetic fixtures only; user-approved real device smoke outside public repository.
10. Release staged, no real data until privacy gate. Every additional integration needs permission, license, threat model and acceptance evidence.

Все ссылки — документация/кандидаты, не утверждение о доступности конкретных пользовательских разрешений. Перед implementation фиксировать supported version/commit, проверять лицензии библиотек и SDK, проводить маленькие platform PoC с синтетическими данными. Не добавлять неподтверждённые обходы в проект.

## Native Windows packaging (decision 24.11.2026)
[ADR-011](adr/011-native-windows-python.md) is authoritative: PyInstaller onedir + Inno Setup, FastAPI/Uvicorn embedded, Python collector, SQLite WAL/FTS5/NumPy, asyncio durable jobs. References and trade-offs in ADR. No Docker/WSL/PostgreSQL/Rust runtime; browser extension + local LLM optional separate applications. Test frozen binary, privacy and upgrade on clean Windows VM; exact vectors benchmark before adding dependency.
